# _archive

One-off artifacts from earlier development sessions, moved out of the repo root
during the June 2026 audit so the root only holds real configuration and app code.
Nothing here is imported, built, or deployed (`_archive` is excluded in
`tsconfig.json` and `.dockerignore`). Safe to delete once no longer useful.

- `tests/` — ad-hoc Python/JS smoke scripts written by previous agents
- `reports/` — Railway log analyses, audit reports and planning docs
- `screenshots/` — UI captures used for visual QA
- `scripts/` — throwaway debugging utilities

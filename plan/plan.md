# Refresh DynoPay's brand icon (Part 1)

## Goal
Refine DynoPay's own product icon — keeping the recognisable "dyno + coin" identity — and roll the refreshed mark out consistently everywhere it appears, inside the app and outside.

## Context (so the scope is clear)
DynoPay already has a single, consistent brand mark: the indigo "conversion coin" (a coin with two looping arrows = crypto in → stablecoin out). It's already used for the browser tab icon, the installable/home‑screen app icon, the in‑app logo, the press kit and the default social‑share image. So this is a **refresh of an existing system**, not a build from zero. (The separate idea of letting each merchant build their own icon is parked for now.)

## How it will go

**Step 1 — Choose the mark.** A small set of refined "coin" concepts will be presented for you to pick from before anything ships. All keep the coin‑and‑arrows identity so DynoPay stays instantly recognisable; they differ in polish — cleaner geometry, better legibility at tiny sizes (a 16px browser tab), and an optional subtle depth/gradient. Because you're open on colour, the options will include the current indigo **and** one or two alternative palettes to compare side by side.

**Step 2 — Produce the full set from the chosen concept**, so the icon looks pixel‑consistent everywhere:
- **In‑app:** sidebar/header logo, the collapsed/compact icon, and loading states.
- **Browser & devices:** tab favicon (works on light and dark tab bars), the installable/home‑screen app icon (incl. the Android "safe‑zone" version), and the Apple touch icon.
- **Outside the app:** the default social‑share/preview image, the email header logo, and the downloadable press‑kit logos (black, white, icon‑only).

**Outcome:** one refreshed DynoPay icon, shown identically across tabs, installs, in‑app chrome, emails and social shares — with old cached copies refreshed so no one keeps seeing the previous icon.

## Decisions for you
1. **Which concept** — you pick from the options presented in Step 1.
2. **Colour** — keep indigo, or adopt one of the alternative palettes shown.
3. **If you pick a new palette:** the app's accent colour is currently tied to the brand indigo in places. Default assumption is the in‑app accent shifts to match the new palette; say so if you'd rather keep the current accent and only recolour the icon itself.

## Out of scope (for now)
- Letting each merchant build/upload their own brand icon (the parked Part 2).
- Replacing the app's general interface icons (menus, buttons, coin symbols) — those stay as they are. This is only the DynoPay brand mark.

## Assumption
Concepts and palette options are shown for your approval **before** the full icon set is generated and rolled out.

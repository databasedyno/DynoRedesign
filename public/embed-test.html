Merchant test page

This simulates a merchant site embedding the Dynopay checkout via /v1/embed.js.

In production your server creates the session (POST /api/user/embed/session with your secret x-api-key) and returns client_secret. For this test page, pass it as ?cs=<client_secret> in the URL.

Phase 2 — Buy Button (no merchant server needed)

Renders <dynopay-buy-button> as a native button. Attributes accepted: publishable-key (pk_live_/pk_test_), amount, currency, label, mode="modal|redirect|inline", theme="dark|light". Pass a real pk via ?pk=pk_test_xxx in the URL and it will render below.
